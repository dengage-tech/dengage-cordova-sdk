# Changelog

## [1.0.27] - 2026-07-27

### Updates

- Bump Android Dengage SDK from `6.0.92` to `6.0.95`
- Bump iOS Dengage SDK CocoaPods spec from `~> 5.96` to `~> 5.101`
- Document bundled native SDK versions in README
- `INSTALL_DENGAGE_GEOFENCE` defaults to **`false`** on Android and iOS (opt-in via `config.xml`); iOS no longer always installs the `DengageGeofence` pod

## [1.0.26] - 2026-06-12

### Updates

- Bump Android Dengage SDK to `6.0.92`
- Bump iOS Dengage SDK CocoaPods spec to `~> 5.96`
